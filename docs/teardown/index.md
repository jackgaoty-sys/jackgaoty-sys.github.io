# 源码拆解

读别人写的生产级代码，一级一级往下拆。目标不是"看过"，是能用大白话把它的设计讲出来，包括作者为什么这么选。

和[学习路线](/learn/)的区别：这里读的是**已经存在的代码**；那边是系统地学一门东西。

## 拆解 Pi Agent

一个真实的 TypeScript Agent Harness。从主循环、工具执行、上下文压缩，到多模型统一抽象，六级路线逐层读下来。

我最关心的问题是：**生产代码比玩具代码多出来的那几百行，到底在处理什么。**
