# 01 · 意图识别

## 一、什么是意图识别？

意图识别的目的是让Agent系统能理解客户文本中的需求，并归入系统预先定义好的类别中。

意图识别就是Agent的需求工程。Agent不同于纯对话型的LLM，不只是回答问题，它还会调用工具、制定计划，甚至改变外部状态。在行动之前，它必须先弄清楚：用户究竟想达成什么结果。

意图识别的逻辑不是通过某个关键词来定义客户的意图，或给请求贴一个固定标签。更实用的做法是形成一份可更新的任务模型，比如：业务对象+动作=意图

## 二、举个例子

### 2.1 求职场景下的意图
举个例子，我最近自己在做一个用于求职的Agent，下面是我做的一部分意图分类：

| 一级意图标签 | 二级意图标签 | 需求示例 |
|---|---|---|
| 职业定位 | 方向探索 | “我适合做产品经理还是数据分析？|
| 职业定位 | 目标设定 | “我希望三个月内找到 AI 应用开发实习，应该设定哪些阶段目标？” |
| 职业定位 | 能力差距 | “如果想申请 AI Agent 工程师，我目前还缺少哪些能力？” |
| 职位发现 | 搜索 | “帮我找多伦多最近发布的初级AI开发岗位。” |
| 职位发现 | 筛选 | “只保留支不要求三年以上经验的岗位。” |
| 职位分析 | JD 解析 | “帮我拆解一下这个 JD 的核心职责和硬性要求。” |
| 职位分析 | 匹配度分析 | “根据我的经历，我和这个岗位的匹配度怎么样？” |
