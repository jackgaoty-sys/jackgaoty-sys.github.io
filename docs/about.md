# 关于这个Blog

这里是我的个人技术Blog，我希望能在这里讲清楚我感兴趣并学习，实践过的所有技术。

我认为随着LLM的coding能力愈发强大，工程师的自我定位也该越贴近本质-解决问题，实现需求。
AI 工具可能成为非常强大的生产力杠杆，但目前还不是消除软件复杂性的银弹；它主要把瓶颈从“编写代码”转移到“定义、指导、验证和维护代码”。

## 岗位意向

正在找 **AI Agent 工程 / 交付方向**（FDE、AI 应用工程、解决方案）的实习和校招机会。

## 技术栈

-**数理基础**：精通微积分、线代、概率统计，持多项数据工程认证。
-**后端开发**：熟练 Python、FastAPI、SQL、Bash，可搭建模块化接口、自动化数据校验体系。
-**工程交付**：掌握Git，Linux，Docker。了解CI/CD理念。
-**AI  研发**：熟悉机器学习、神经网络、大模型应用，可完成 Agent 开发与 AI 方案 POC 验证。拆解并自主构建过Agent Harness。
-**数据处理**：擅长爬虫、数据流水线，构建估值、风险评分、Embedding 行业知识库。
-**业务交付**：具备项目路演、方案设计、成本测算、多团队协同与标准化 SOP 沉淀能力。
