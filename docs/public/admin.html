需要一个 GitHub Token 才能提交。Token 只存在这台浏览器的 localStorage 里，不会发给任何第三方——这个页面直接调 GitHub API。

  1. 打开 Fine-grained token 创建页
  2. Repository access 选 Only select repositories → 只勾 jackgaoty-sys.github.io
  3. Permissions → Repository permissions → Contents 设为 Read and write
  4. 生成后粘到下面

务必用 fine-grained token 并且只授权这一个仓库。这样即使 token 泄漏，能被改的也只有这个博客。
