# README.md

这里是「沙箱逃逸.log」的索引说明。本站用于记录我在 AI Agent 开发、源码阅读与日常折腾中的工程笔记。

## 频道划分

站内文章按内容性质分为三个频道：

- **`trace/`**：踩坑实录与项目复盘。记录从零搭建系统、调优工作流或重构代码时的真实过程与折中取舍（Trade-offs）。
- **`dump/`**：源码拆解与技术笔记。针对开源框架、论文或具体技术模块的拆解与梳理。
- **`escape/`**：关掉 IDE 后的胡思乱想。关于技术趋势、产品体验或个人状态的记录。

## 成熟度

文章标题旁的标签表示这篇笔记写到了什么程度，允许先发半成品、再慢慢改：

- **`[draft]`**：草稿。想法刚落地，结论可能会变。
- **`[wip]`**：进行中。主体写完了，还在补充和修订。
- **`[stable]`**：定稿。反复推敲过，可以放心引用。

每篇文章末尾的 `git log` 链接可以看到它的完整修订历史。

## 编号规则

- **全局递增**：所有文章无论属于哪个频道，共用同一套全局递增序号（`#001`, `#002`, `#003`...），按首次发布的时间顺序分配。
- **固定不复用**：序号一旦分配即作为该文章的固定标识，后续即使增删或大幅修改内容，原序号也不再变动或复用。
- **`#000` 保留**：`#000` 固定分配给当前这份 `README.md`，作为站点的基准说明文档。
